# はじめてのお店で「浮きたくない」を支えるサービス

> 状態：検討中（最終更新 2026-10-31（0回目・心の声4コマを追記））
> 仮タイトル：ハウスルール／かおパス（未決定）
> 方向性：**旅猫と一緒に霧の街を広げていく。お店のハウスルールが合鍵として溜まっていく**

---

## 0. 軸

**初めての場所で「浮きたくない」という心情を理解したサービスにすること。**

- **ジャンルは絞らない。むしろそれをポイントにする**
- カフェやコスメに限らず、おしゃれなアパレル、サーキットなど「初めての場所」ならどこでも対象

## 1. 出発点

周りが慣れている雰囲気のお店（だいたいおしゃれ）で、初心者っぽい動きをしてしまうのが恥ずかしい。そんな時のサポートを作りたい。

- 作りたいのは **アプリ／サービス**。広げ方は **SNS発信** が正解ルートの想定
- 狙う層は **ライト**（高校生でも使える）。**男女を限定しない**
- **ゲームっぽい** のに、恥ずかしい気持ちがあっても **それを肯定できる** もの
- 二人ならあまり恥ずかしくない（初デートは別）。問題は **一人で初めてのことをする時** のそわそわ・キョロキョロ

## 2. 気持ちの分解（ここが核）

| 質問 | 答え |
|---|---|
| 一番そわそわする瞬間 | **入った瞬間** と **注文** が同じくらい |
| うまくいった後の気持ち | 「**なんだ大丈夫じゃん**」という安心 |
| 「肯定」とは | 恥ずかしさが消えることではなく、**恥ずかしいままでいいと思えること** |
| 想定シーン | 一人で初めてやること全般。例：一人カフェ、初めてのショッピングモールで一人でコスメを買う、おしゃれなアパレル、サーキット。**ジャンルは絞らない** |
| 最中にスマホは使える？ | ドキドキの最中は余裕がない。でもスマホには逃げる。逃げた先で **実はやることがない** |

### 一番強い気持ち
**浮きたくない。** 気になるのは「**その店独自のルールに、ちゃんと従えているか？**」ということ。

→ 不安の正体は「どこまでがルールか分からない」こと。だから知識を足すのではなく、**ルールの範囲を区切る**。
「この店のルールはこれだけ。それ以外は自由」と分かれば、**最初から経験者の顔で入れる**。

## 3. 現在の方向性

**お店ごとの「ハウスルール」をスマホに入れておくサービス**

- **入る前**：ルールは3つくらいだけ表示＋「それ以外は気にしなくていい」
- **最中**：スマホに逃げた時、ルールが大きく出ているだけ。読む・操作するは無し
- **出た後**：「このルール合ってた？」をワンタップ → これが「なんだ大丈夫じゃん」の瞬間になる

### ルールをどこから持ってくるか
1. **ジャンル別の基本ルール**（最初に自分で作る）
   お店のルールはほとんどが業態共通（先レジ、返却口、水セルフなど）。数十種類の型で8割はカバーできる
2. **お店ごとの差分**（自分で種をまく）
   デートスポット選びのサイトでやっている方法と同じ。最初は1エリア・30〜50店に絞る。発信のネタにもなる
3. **行った人のワンタップ確認**（自然に増える）
   「合ってた／違った／他にもあった」だけ。長いレビューはいらない
4. **データのない店**
   外観やメニューを撮るとAIがジャンルを判断し「たぶんこのルール」を出す（未確認マーク付き）

※Googleマップの口コミなどの自動収集は規約に触れやすいので避ける

## 4. 楽しさレイヤー（ここを引き続き考える）

**心配：シンプルすぎるとつまらないのでは？**

### 4-1. 自分の街が広がっていく
- 最初の地図は霧がかかっている。「はじめて」を1回こなすたびに、そのお店の周りの霧が晴れる
- 自分の行動範囲＝自分の世界が、目に見えて広がっていく
- ドキドキした回数がそのまま地図の広さになるので、恥ずかしさが「広げた証」として肯定される

### 4-2. 猫と旅する
- 気まぐれな旅猫が、霧の中を先に歩いてお店のハウスルールをくわえて持ってくる
- 猫は怖がらない。案内役であって守る対象ではない（「自分よりビビりな相棒」案とは別物）
- 猫は性別を問わず好かれやすく、キャラクターとして発信しやすい
- 4-1と組み合わせると「猫が霧を晴らしていく街の地図」になる

### 4-3. ハウスルール＝合鍵
- お店ごとのルールが「鍵」のカードになっている
- 行って「合ってた」を押すと、その鍵が **合鍵** になる
- 「この街の合鍵、何本持ってる？」がコレクションの楽しさになる

### 4-4. 顔パス
- 「経験者の顔で入れる」をそのまま名前にする
- ルール3つ＝そのお店の **顔パス**
- 3回行くと「常連」になり、カードが裏返って自分だけの常連メモになる

### 4-5. 珍ルール図鑑
- 同じカフェでも店ごとに違う、ちょっと変わったルールを集める
  （例：注文時に名前を聞かれる／席は店員さんが案内する）
- 珍しいルールほどレア。知らなかったことが、恥ではなく **発見** になる
- そのままSNSネタにもなる

### ✅ 採用：組み合わせ案
**旅猫と一緒に、霧の街を広げていく。お店ごとのハウスルールが合鍵になって溜まっていく。**
（4-1 × 4-2 × 4-3）

4-4（顔パス）、4-5（珍ルール図鑑）は、この上に乗せられる要素として保留。

## 8. ハウスルールの型（2問だけ）

どのジャンルでも使える共通の問いは、この2つだけにする。

1. **着いたら、まず何をする？**（行動の流れ。入る前のことも含む）
2. **気にしなくていいこと**（みんなが心配しがちだけど、実は大丈夫なこと）

### 「やっちゃダメなことは？」をやめた理由

- 「テスターを直接唇に塗らない」のような**当たり前のマナー**を書いても価値がない。むしろ上から目線になる
- 浮きたくない人は、マナーは分かっている。怖いのは「**慣れてないのがバレること**」と「**この後どうなるか分からないこと**」
- だから「ダメなこと」で縛るのではなく、「**それ、気にしなくていいよ**」で心配をほどく方が感情に寄り添える。恥ずかしいまま行っていい、という肯定にもなる

（「声をかけるタイミングは？」は、誰に・何をかが曖昧なので外した）

### 試してみた（内容は仮。実際のお店で要確認）

| 場所 | 着いたら、まず何をする？ | 気にしなくていいこと |
|---|---|---|
| セルフ式のカフェ | レジに並んで注文と支払い。席はその後 | メニュー名が読めなくても大丈夫。「おすすめどれですか？」は常連も普通に聞いている |
| 昔ながらの喫茶店 | 空いている席に座って待つ。店員さんが来てくれる | 自分からレジに行かなくていい。一人で長めに座っていても誰も気にしない |
| デパートのコスメカウンター | 見ているだけでOK。気になったら近くのスタッフさんに一言 | 座ってタッチアップしてもらっても、買わずに帰っていい。「今日は見るだけで」で大丈夫 |
| ショッピングモールのコスメ売り場 | 自由に見て、決まったらレジへ | 同じ棚の前に長くいても変じゃない。みんな迷っている |
| おしゃれなセレクトショップ | 「いらっしゃいませ」に軽く会釈して、自由に見る | 話しかけられても「見てるだけです」でOK。何も買わずに出ても失礼じゃない |
| 古着屋 | 自由に見る。試着したい時はスタッフさんに一声 | 値段を見てそっと戻すのは普通のこと。サイズが分からなければ聞けばいい |
| サーキット（観戦） | 入場ゲートでチケットを見せる | 車やレースに詳しくなくても大丈夫。音と迫力を楽しみに来ている人も多い |
| サーキット（初めての走行） | 受付をして、ドライバーズブリーフィングに出る | 速く走れなくていい。普通の車で来ている人もいる。初心者向けの枠もある |
| 銭湯・サウナ | 靴を下駄箱へ。受付で支払い | タオルや石けんを忘れても、受付で買えたり借りられたりすることが多い |
| 美容院 | 受付で名前を伝えて、案内されるまで待つ | 希望がうまく言えなくても、写真を見せればOK。会話が苦手なら話さなくていい |

### 試して分かったこと

- **1問目で「流れ」、2問目で「心」をケアする**という役割分担になる
- 2問目は、ほぼ「**〇〇しても大丈夫／〇〇しなくていい**」の形になる。これが恥ずかしさの肯定そのもの
- 2問目は、実際に行った人の「心配してたけど大丈夫だった」から集めるのが一番強い
  → 帰りのワンタップ確認を「**心配してたけど大丈夫だったことは？**」にすれば、そのまま2問目のデータになる
- ジャンルがまったく違っても（コスメ vs サーキット）同じ型で書けるので、**ジャンルを絞らない方針と合う**

## 9. 深掘り（2026-10-31）

### 判断基準
**それを使った人が、実際にお店のドアを開けるところまで行くか。**
表面的な情報や機能だけでは「だから行動しない」になる。

### 分かったこと
- 「気にしなくていい」ことすら分かっている。それでも **目の前にいるのが人間だから、気にせずにはいられない**
- 気にしてしまう理由
  1. 目の前の人が「知らない人」だから身構える
  2. 初めてなのを隠そうとしているから「バレたらどうしよう」が続く
- 路線は2つあり、まだ決めきれていない（会話しながら色々な案を見て決めたい）
  - **路線1：浮かないようにしてあげる**
  - **路線2：気にしてしまうことを楽しむ**

### ✅ 採用候補

#### 路線1 → 0回目（下見ゲーム）
- 人が怖いのは「その店」ではなく「**初めて**」であること。2回目は同じ状況でもほとんど緊張しない → **初めてをなくす**
- 行く前に、そのお店を **ミニゲームのステージとして一度プレイ** する（旅猫を操作して、ドア → レジ → 注文 → 席、までクリア）
- 体が「一度やったこと」として覚えるので、本番は2回目の動きになる。迷わない＝立ち止まらない・キョロキョロしない＝浮かない
- 本番でクリアすると、そのステージが合鍵になる
- 読む知識ではなく、**体験として先に済ませておく** のがポイント
- 店内の撮影動画を集める形はトラブルになりやすいので、イラストのステージにする

#### 路線2 → 心の声4コマ
- 恥ずかしい瞬間は、あとで話すと一番おもしろい話になる
- 「浮くかもしれないから行かない」を「**浮いた方がおいしいから行く**」にひっくり返す
- 出た後に心の声を話す／短く書くだけで、その日の **4コマ漫画** になる（主人公は自分と旅猫）
- そわそわした日ほど話がおもしろい＝恥ずかしさが **ネタの素材** になる
- SNSにそのまま投稿でき、共感で広がる（SNSで広げる方針と直結）

#### 2つの路線のつながり
**0回目で予習 → 本番は浮かずに通る → それでもドキドキした分は4コマになる**
どちらかを選ばなくても成立する。

### 保留
- 観客の少ない時間（空いている時間を教える。状況を変えるので確実だが地味）
- ドキドキの記録（心拍のグラフ）

## 10. 0回目のステージはどのくらいの手間で作れるか

### 前提：何を再現すれば「2回目の体」になるか
- 必要なのは **動きの順番** と **ざっくりした向き**（ドアを開けたら、まずどっちへ行くか）
- 正確な見取り図、内装、メニューの全部はいらない
- → **お店ごとに一から作る必要はない**

### 作り方：「流れの型」×「お店ごとの差分」

**① 流れの型（ジャンルではなく、動きの順番で分ける）**

| 流れの型 | 当てはまる場所の例 |
|---|---|
| 先に注文・支払い型 | セルフ式カフェ、ファストフード |
| 座って待つ型 | 喫茶店、レストラン |
| 券売機型 | ラーメン屋、定食屋 |
| 自由に見て回る型 | アパレル、セレクトショップ、古着屋、雑貨屋、セルフのコスメ売り場 |
| カウンター接客型 | デパートのコスメカウンター、時計・ジュエリー |
| 受付して呼ばれる型 | 美容院、ネイル、整体 |
| 入場ゲート型 | サーキット観戦、ライブ、美術館 |
| 受付→説明→体験型 | サーキット走行、ボルダリング、体験教室 |
| 靴を脱いで受付型 | 銭湯、サウナ、岩盤浴 |

ジャンルは無限でも、**動きの順番は10種類前後** に収まる。ジャンルを絞らない方針でも作れる理由はここ。

**② お店ごとの差分（フォームで5〜10分）**
- ドアを開けたら、レジ（受付）は 左／正面／右
- 注文と受け取りは 同じ場所／別の場所
- 席は 自由／案内される
- 水・返却口などは あり／なし、どのあたり
- その店で言われるひと言（「店内ですか？」など）

→ 入力内容から、型のステージに部品を置いて自動で組み立てる

### 手間の目安（ざっくり）

| 作るもの | 手間 |
|---|---|
| ステージを動かす仕組み（タップで猫が進む・会話が出る） | 1〜2週間 |
| 流れの型1つ（絵と流れ） | 1〜2日 × 型の数 |
| お店1軒の追加 | フォーム入力で5〜10分 |

### いきなり作る前に：紙芝居版で効果を確かめる
- 本格的なゲームを作る前に、絵を数枚スワイプするだけの **紙芝居版** で「0回目の効果」があるかを確かめる
- 1つのお店を題材に1〜2日で作れる
- 5〜10人に「紙芝居 → 実際に行く」をしてもらい、**2回目のような感覚になったか** を聞く
- 効果があれば、ステージの仕組みを作る

### 紙芝居版の試作
- ファイル：[`zero-kaime.html`](../zero-kaime.html)（セルフ式カフェの例）
- 光っている場所をタップすると旅猫が歩き、レジでは店員さんとのやりとりを選ぶ
- クリアで「下見の鍵」→ 本番後に「行ってきた」で「2回目みたいだった？」と心の声ひとことを聞き、合鍵になる
- テスト用に、答えをコピーして作った人に送れるようにしてある
- お店のデータは `STORE` の中身だけ。ここを差し替えれば別のお店になる
